# 1248 · Un extraño en Castilla

Aventura gráfica 2D point-and-click con humor y reconstrucción histórica de Talavera junto al Tajo en 1248.

## Estado
Preproducción y LAB01 jugable. Motor Canvas de Claude con corrección de parpadeo validada por el usuario en Pixel 8 Pro. No confundir imágenes conceptuales con assets listos para producción.

## Organización
- `builds/`: HTML jugables, sin sobrescribir versiones validadas.
- `src/` y `data/`: código modular y datos del juego (pendientes de importar desde el ZIP C01).
- `assets/scenes/`: fondos y capas de ribera, aceña y embarcadero.
- `assets/characters/`: protagonista, Durán y Alfonso.
- `assets/items/`: objetos interactivos.
- `art/concepts/`: láminas y referencias, NO sprites técnicos.
- `docs/technical/`: auditorías, arquitectura y contrato de recursos.
- `docs/design/`: historia, guion, puzles y dirección artística.
- `archive/`: material previo y experimentos no canónicos.

## Versiones
- `1248_LAB01_MOTOR.html`: laboratorio inicial C01.
- `1248_LAB01_FIX_PARPADEO.html`: referencia funcional corregida; preservar original.
- `1248_PROYECTO_C01.zip`: proyecto fuente completo de Claude.

## Regla
Dúo Acero es otro proyecto y no se modifica. El rigor histórico se distingue de las hipótesis artísticas y la ficción narrativa.

Consulta `docs/INVENTARIO_MATERIAL.md` para el inventario del material recopilado en la conversación.
